# Domain Name Brainstormer（域名头脑风暴）

本 skill 通过生成有创意的候选并核对实际可注册情况，帮你为项目找到合适的域名。

## 何时使用本 skill

- 开启新项目或公司
- 发布产品或服务
- 建立个人品牌或作品集站点
- 对现有项目重新品牌化
- 为 side project 注册域名
- 当首选域名被占用时寻找可用替代

## 本 skill 能做什么

1. **理解你的项目**：分析你在做什么、面向谁
2. **生成有创意的名字**：产出相关、易记的域名选项
3. **检查可用性**：核对跨多个 TLD 哪些是真的可以注册
4. **多种后缀**：建议 .com、.io、.dev、.ai、.app 等
5. **提供备选**：当首选已被占用时给变体
6. **品牌洞察**：解释为什么某些名字更好用

## 用法

### 基础头脑风暴

```
I'm building a project management tool for remote teams. 
Suggest domain names.
```

```
Help me brainstorm domain names for a personal finance app
```

### 指定偏好

```
I need a domain name for my AI writing assistant. 
Prefer short names with .ai or .io extension.
```

### 带关键词

```
Suggest domain names using the words "pixel" or "studio" 
for my design agency
```

## 域名命名技巧

### 好域名的特征

✓ **短**：理想 15 字符以内
✓ **易记**：容易回忆、拼写
✓ **可口播**：能在对话中说出来
✓ **有描述性**：暗示你做什么
✓ **可品牌化**：独特到能脱颖而出
✓ **没有连字符**：口头分享更容易

### TLD 指南

- **.com**：通用、可信、适合企业
- **.io**：科技创业公司、开发者工具
- **.dev**：面向开发者的产品
- **.ai**：AI/ML 产品
- **.app**：移动或 Web 应用
- **.co**：.com 的替代
- **.xyz**：现代、创意项目
- **.design**：创意/设计机构
- **.tech**：科技公司

## 常见 workflow

### 创业发布
1. 描述你的创业 idea
2. 得到 10-15 个跨 TLD 的域名建议
3. 审阅可用性与价格
4. 挑选前 3 个最爱
5. 立即注册

### 个人品牌
1. 分享你的姓名与职业
2. 得到变体（firstname.com、firstnamelastname.dev 等）
3. 同时核对社交媒体用户名可用性
4. 跨平台注册一致的品牌标识

### 产品命名
1. 描述产品与目标市场
2. 得到有创意、可品牌化的名字
3. 检查商标冲突
4. 核对域名与社媒可用性
5. 用目标受众测试名字

## 成功要点

1. **动作要快**：好域名被抢得很快
2. **注册变体**：拿下 .com 和 .io 保护品牌
3. **避免数字**：口头沟通困难
4. **核对社交媒体**：确保 @username 也可用
5. **念出来**：测试是否好读
6. **核对商标**：确保没有法律冲突
7. **着眼长期**：5 年后它还说得通吗？

## 价格背景

给建议时会标注：
- 标准域名：每年约 $10-15
- 优质 TLD（.io、.ai）：每年约 $30-50
- 已占域名：挂牌者的市场价
- 优质域名：数百到数千美元
