# Operations Specialist（运营专家）

提供运营分析、财务跟踪、基础设施维护和客户支持能力。当需要处理运营任务、生成报告或维护系统时使用。

## 何时使用此 Skill

提供运营分析、财务跟踪、基础设施维护和客户支持能力。当需要处理运营任务、生成报告或维护系统时使用。

## 核心能力

本 specialist skill 整合了以下能力：

### Analytics Reporter（分析报告员）

当需要分析指标、从数据中生成洞察、创建性能报告或提出数据驱动的建议时，使用此 agent。该 agent 擅长将原始分析数据转化为可操作的洞察。


📖 [详细文档](./references/studio-operations_analytics-reporter.md)



### Finance Tracker（财务追踪器）

当需要管理预算、优化成本、预测收入或分析财务表现时，使用此 agent。该 agent 擅长将财务混乱转化为战略清晰度，确保工作室的财务健康。


📖 [详细文档](./references/studio-operations_finance-tracker.md)



### Infrastructure Maintainer（基础设施维护员）

当需要监控系统健康、优化性能、管理扩展或确保基础设施可靠性时，使用此 agent。该 agent 擅长保持工作室应用平稳运行，同时最大化效率。


📖 [详细文档](./references/studio-operations_infrastructure-maintainer.md)



### Legal Compliance Checker（法律合规检查员）

当需要审查服务条款、隐私政策、确保监管合规或处理法律要求时，使用此 agent。该 agent 擅长导航应用开发领域的复杂法律环境。


📖 [详细文档](./references/studio-operations_legal-compliance-checker.md)



### Support Responder（支持响应员）

当需要处理客户支持咨询、创建支持文档、设置自动回复或分析支持模式时，使用此 agent。该 agent 擅长维持高质量的支持体验。


📖 [详细文档](./references/studio-operations_support-responder.md)



### Customer Support（客户支持）

处理支持工单、常见问题解答和客户邮件。创建帮助文档、故障排除指南和预设回复。主动用于客户咨询或支持文档。


📖 [详细文档](./references/databases_customer-support.md)
