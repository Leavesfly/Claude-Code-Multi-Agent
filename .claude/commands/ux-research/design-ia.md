# 设计信息架构

为指定产品创建全面的信息架构。

## 工作流程

### 步骤 1：加载所需技能

加载以下技能：

- `information-architecture` - IA 方法论和模式

### 步骤 2：理解 IA 上下文

收集关于 {{ product }} 的上下文信息：

范围：{{ scope | default: "完整站点" }}

了解：

- 存在或将存在哪些内容？
- 主要用户群体是谁？
- 关键用户任务是什么？
- 是否有现有的 IA 或内容清单？

### 步骤 3：生成 IA 架构师 Agent

使用以下提示词生成 `ia-architect` agent：

```text
为以下产品设计全面的信息架构：{{ product }}

范围：{{ scope | default: "完整站点" }}

提供：

1. 内容分析
   - 识别的内容类型
   - 内容关系
   - 体量和增长考虑

2. 用户分析
   - 主要用户细分
   - 关键用户任务和目标
   - 查找行为（浏览 vs. 搜索）

3. 组织系统
   - 主要组织方案
   - 层级结构
   - 分面维度（如适用）
   - 元数据要求

4. 站点地图
   - 视觉层级图
   - 页面类型和模板
   - 深度分析
   - 交叉链接策略

5. 导航设计
   - 全局导航结构
   - 本地/上下文导航
   - 实用导航
   - 面包屑策略
   - 移动端考虑

6. 标签系统
   - 导航标签
   - 类别标签
   - 关键术语决策
   - 标签测试建议

7. 搜索策略
   - 搜索范围
   - 过滤器和分面
   - 搜索结果组织

8. 分类体系（如适用）
   - 类别层级
   - 术语定义
   - 同义词和相关术语
   - 治理方法

9. 验证建议
   - 卡片分类方法
   - 树测试计划
   - 首次点击测试

10. 实施指导
    - URL 结构
    - SEO 考虑
    - CMS 要求

使用 information-architecture 技能获取方法论指导。
输出完整的 IA 文档。
```

### 步骤 4：生成验证计划

提供验证 IA 的计划：

- 卡片分类研究设计
- 树测试规范
- 导航可用性测试

## 示例用法

```bash
# 完整站点 IA
/ux-research:design-ia "企业文档门户"

# 特定部分 IA
/ux-research:design-ia "电子商务产品目录" --scope "类别导航"

# 导航重新设计
/ux-research:design-ia "企业网站" --scope "仅导航"
```
