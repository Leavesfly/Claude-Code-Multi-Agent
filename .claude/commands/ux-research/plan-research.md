# 创建用户研究计划

为指定主题设计全面的用户研究方案。

## 工作流程

### 步骤 1：加载所需技能

加载以下技能：

- `user-research-planning` - 研究方法论和规划

### 步骤 2：理解研究上下文

收集关于 {{ topic }} 的上下文信息：

研究类型：{{ type | default: "both" }}

如有需要，提出澄清问题：

- 这项研究将告知哪些决策？
- 你对用户已经了解什么？
- 你的时间线和预算是多少？
- 你能接触到用户吗？

### 步骤 3：生成 UX 研究员 Agent

使用以下提示词生成 `ux-researcher` agent：

```text
为以下主题创建全面的用户研究计划：{{ topic }}

研究重点：{{ type | default: "生成式和评估式" }}

提供：

1. 研究目标
   - 主要研究问题（3-5 个）
   - 这将告知哪些决策
   - 研究的成功标准

2. 方法论选择
   - 推荐的研究方法
   - 每种方法的理由
   - 方法顺序和理由

3. 参与者画像
   - 目标用户细分
   - 纳入标准（必须具备）
   - 排除标准
   - 每种方法的样本量及理由

4. 研究设计
   - 研究时间线
   - 每种方法的会话结构
   - 要探索的关键主题

5. 所需材料
   - 筛选问卷
   - 讨论指南大纲
   - 同意书和后勤模板

6. 交付物
   - 利益相关者将收到的输出
   - 交付格式和时间线
   - 如何分享发现

7. 风险和缓解
   - 招募挑战
   - 偏见考虑
   - 时间线风险

使用 user-research-planning 技能获取方法论指导。
输出完整的研究计划文档。
```

### 步骤 4：生成研究材料

根据计划，提供生成以下内容：

- 详细筛选问卷
- 完整访谈/讨论指南
- 同意书模板
- 笔记模板

## 示例用法

```bash
# 为新产品规划研究
/ux-research:plan-research "老年人移动银行应用"

# 规划生成式研究
/ux-research:plan-research "开发者工作流痛点" --type generative

# 规划评估式研究
/ux-research:plan-research "结账流程优化" --type evaluative
```

## 输出格式

```markdown
# 研究计划：[主题]

## 执行摘要
[1-2 段概述]

## 研究目标
### 主要问题
1. [问题]
2. [问题]
3. [问题]

### 要告知的决策
- [决策 1]
- [决策 2]

## 方法论

### 方法 1：[名称]
- **目的：** [为什么使用此方法]
- **参与者：** [数量和类型]
- **持续时间：** [会话长度]
- **时间安排：** [时间线中的位置]

[继续每种方法...]

## 参与者画像

### 细分
| 细分 | 标准 | 样本量 |
|---------|----------|-------------|
| [名称] | [标准] | [N] |

### 筛选要点
- [关键筛选问题]
- [关键筛选问题]

## 时间线

| 周 | 活动 | 交付物 |
|------|----------|-------------|
| 1 | [活动] | [输出] |
| 2 | [活动] | [输出] |

## 交付物
- [交付物 1]
- [交付物 2]

## 下一步
1. [立即行动]
2. [立即行动]
```
